# compactionlaundering.com

Landing page for **Compaction Laundering**, an AI coding agent vulnerability class discovered by [Pixee](https://www.pixee.ai).

Full research: https://www.pixee.ai/blog/compaction-laundering · Paper: https://arxiv.org/abs/2610.29869

Static site served by GitHub Pages. `og.png` is rendered from `og.html` with headless Chrome. Colors, fonts and logo follow pixee.ai.
